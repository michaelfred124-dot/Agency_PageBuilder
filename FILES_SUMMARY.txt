THE USER JOURNEY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Homepage
   └─ [Get Started] button
      └─ → /get-started

2. /get-started (IndustrySelectorPage)
   └─ User sees 9 industries
   └─ Clicks "Local Service Business"
      └─ → Template Gallery

3. Template Gallery (TemplateGalleryPage)
   └─ User sees 4 layouts
   └─ Clicks "Hero + Services Grid"
   └─ [Choose This] button
      └─ → /signup?template=hero-grid-features&industry=local-service

4. /signup (Quick Form)
   └─ 3 fields only:
      ├─ Full Name
      ├─ Email
      └─ Business Name
   └─ [Create Account]
      └─ → /dashboard/onboarding

5. /dashboard/onboarding (OnboardingChecklist)
   └─ Main dashboard after signup
   └─ Shows 3 sections:
      ├─ Photos & Media (logo, hero, team photos)
      ├─ Text Content (tagline, about, services, contact)
      └─ Branding (colors)
   └─ Progress bar (0% → 100%)
   └─ Timeline (Phase 1→2→3→4)
   └─ Next: Agency builds for 3-5 days

6. Review Phase
   └─ Agency sends live preview link
   └─ Shows video walkthrough
   └─ Client approves/requests changes
      └─ → Site goes live

7. Live Site
   └─ Client can edit text/images
   └─ Chat with manager for bigger changes
   └─ Access to analytics, inbox, etc.

DATABASE SCHEMA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Table: onboarding_checklist
├─ id (UUID, primary key)
├─ user_id (UUID, foreign key)
├─ template_id (VARCHAR)
├─ industry_id (VARCHAR)
├─ business_name (VARCHAR)
├─ checklist_data (JSONB) — all form data
├─ phase (VARCHAR) — gathering, building, review, live
├─ created_at (TIMESTAMP)
└─ updated_at (TIMESTAMP)

Table: project_updates
├─ id (UUID, primary key)
├─ user_id (UUID, foreign key)
├─ phase (VARCHAR) — design, development, optimization, ready
├─ title (VARCHAR)
├─ message (TEXT)
├─ video_url (VARCHAR)
└─ created_at (TIMESTAMP)
